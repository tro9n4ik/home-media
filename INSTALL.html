Home.Media v4

Установка на Synology NAS — без консоли, только через веб-интерфейс

DSM 7.2+ · Container Manager 2.x
1
Загрузить файлы на NAS
~2 мин
▼
Нужно скопировать папку с проектом на NAS. Проще всего через File Station в браузере.
Через File Station (браузер)
1
Откройте DSM → File Station и перейдите в папку docker
2
Нажмите Загрузить → Пропустить и загрузите файл home-media-v4.zip
3
Правой кнопкой на zip → Извлечь → извлечь в папку docker
4
Убедитесь что появилась папка:
📁 /docker/hm3
внутри которой файл docker-compose.yml
💡
Где находится папка docker?
File Station → слева в дереве папок → docker. Если папки нет — создайте её: Создать → Создать папку → назовите docker.
2
Открыть Container Manager
~1 мин
▼
Container Manager — это встроенный Docker-менеджер Synology. Если его нет — установите из Package Center.
Шаги
1
Откройте DSM → Package Center и убедитесь что Container Manager установлен
2
Откройте Container Manager из главного меню DSM
3
В левом меню нажмите Project
3
Создать проект из папки
~2 мин
▼
Container Manager умеет читать docker-compose.yml прямо из папки на NAS. Именно этим мы воспользуемся.
Container Manager → Project
1
Нажмите кнопку Create
2
В поле Project name введите: home-media
3
В поле Path нажмите иконку папки и выберите:
📁 docker/hm3
4
Container Manager автоматически найдёт docker-compose.yml и покажет его содержимое — ничего менять не нужно
5
Нажмите Next → Next → Done
⚠️
Первый запуск занимает 5–15 минут — Docker скачивает образы Node.js, Python, PostgreSQL и собирает React. Это только один раз. Прогресс видно во вкладке Log проекта.
4
Подождать сборки и открыть
~10 мин (только первый раз)
▼
Пока контейнеры собираются, можно следить за прогрессом в Container Manager.
Как следить за прогрессом
1
Container Manager → Project → home-media
2
Вкладка Log — видно процесс сборки React и установки Python-пакетов
3
Когда в логе появится строка Application startup complete — всё готово
Открыть Home.Media
1
Откройте браузер и перейдите по адресу вашего NAS на порту 8142
2
Пример: http://192.168.1.100:8142
или через QuickConnect: http://YOURNAS.local:8142
3
При первом входе откроется мастер создания аккаунта — введите логин и пароль
Введите IP вашего NAS:
🚀 Открыть Home.Media
🎉

Home.Media установлен!

Все шаги выполнены. Введите IP вашего NAS и откройте интерфейс.

🚀 Открыть Home.Media
Для перезапуска: Container Manager → Project → home-media → Action → Restart
