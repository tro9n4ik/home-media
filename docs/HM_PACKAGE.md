# Формат .hm пакета

`.hm` — это zip-архив с фиксированной структурой. Ядро распаковывает его,
создаёт venv, ставит зависимости и запускает `app/main.py`.

## Структура

```
plugin.hm (zip)
├── manifest.json      # метаданные (обязателен)
├── requirements.txt   # Python-зависимости (опционально)
└── app/
    ├── main.py        # FastAPI app — точка входа (обязателен)
    ├── plugin_sdk.py  # SDK — скопируйте из plugins/sdk/
    └── web/
        └── index.html # UI плагина (опционально, монтируется на /ui/)
```

Файлы могут лежать как в корне архива, так и в подпапке
(например `my_plugin/manifest.json`) — ядро найдёт первый `manifest.json`.

## manifest.json — полная спецификация

```json
{
  "id": "plugin_id",
  "name": "Название",
  "version": "1.0.0",
  "description": "Описание",
  "has_ui": true,
  "port_hint": 8105,
  "config_secrets": ["api_key"],
  "env": { "MY_VAR": "value" },
  "ui_pages": [
    {
      "title": "Название в меню",
      "path": "/admin/plugins/plugin_id",
      "icon": "search"
    }
  ]
}
```

### Поля

| Поле | Тип | Обязат. | Валидация |
|---|---|---|---|
| `id` | string | да | Только `a-z`, `A-Z`, `0-9`, `_`, `-` |
| `name` | string | да | ≤ 128 символов |
| `version` | string | да | ≤ 32 символов |
| `description` | string | нет | ≤ 512 символов |
| `has_ui` | bool | нет | Есть UI на `/ui/` |
| `port_hint` | int | нет | 1024–65535, должен быть свободен |
| `config_secrets` | [string] | нет | Ключи конфига, маскируемые в бэкапе |
| `env` | object | нет | Дополнительные env-переменные процесса |
| `ui_pages` | [object] | нет | Пункты меню в админке |

### Запрещено

- Поле `port` — ядро само назначает порты из пула 8100–8200. Вместо этого `port_hint`.
- `id` с пробелами, точками и спецсимволами — ломает маршруты и пути.

## Точка входа app/main.py

Запускается как `python app/main.py`. Должна слушать HTTP на порту из
`PLUGIN_PORT` (env) и отвечать на `/health`.

Рекомендуется строить плагин на SDK (`plugin_sdk.py`), который регистрирует
контрактные эндпоинты сам. См. [SDK.md](SDK.md).

## Данные плагина

| Путь | Назначение | Переживает переустановку |
|---|---|---|
| `<plugin>/data/` | Конфиги и данные плагина (`DATA_DIR` в env) | да |
| `<plugin>/.venv/` | Зависимости плагина | пересоздаётся |
| `<plugin>/plugin.log` | Логи процесса | нет (перезаписывается) |
| `<plugin>/.pid` | PID запущенного процесса (внутреннее) | нет |

## Переустановка

При повторной установке того же `id`:
1. Ядро останавливает старый процесс
2. `data/` сохраняется в сторону
3. Файлы распаковываются заново
4. `data/` восстанавливается
5. Процесс стартует с новым кодом и старыми настройками

## Удаление

Удаление стирает папку плагина полностью (включая `data/`).
Перед удалением экспортируйте настройки, если нужен бэкап.

## Ограничения

- Максимальный размер пакета не ограничен, но распаковка и pip install
  идут в фоне — большие пакеты ставятся дольше
- Плагин не должен сам менять `PLUGIN_PORT` — ядро решает
- Плагин не должен запускать других процессов в контейнере ядра —
  всё должно жить внутри процесса плагина (или через HTTP-вызовы другим плагинам)
